Resilient by Design, Not by Connectivity

ReluLayer™ operates entirely on the MCU, so it maintains deterministic flight envelope protection even when RF, SATCOM, or GPS are contested or denied.

GPS/GNSS Denial

When position, velocity, or time solutions become untrustworthy, ReluLayer™ maintains last-known-good kinematic bounds and prevents the flight controller from commanding outside the envelope.

SATCOM / Starlink Blinding

Loss of beyond-line-of-sight C2 does not disable the safety governor. The kernel runs entirely on-chip, enforcing flight envelope limits without cloud or RF dependency.

Adversarial RF Spoofing

Injected false waypoints or commands are treated as untrusted client outputs. ReluLayer™ projects each vector onto the safe polyhedral set before it reaches actuators.

Contested C2 Degradation

The deterministic 0.199 µs loop continues to operate during partial or total primary command-link degradation, giving operators time to recover safe control.

On-Chip Determinism

No cloud, no ML inference, no dynamic allocation. The 326-byte kernel runs in a single bounded loop on the flight MCU, making it inherently resilient to EW-induced communication loss.

  • Zero dynamic heap allocation
  • No RF or SATCOM dependency
  • C ABI ready for Pixhawk integration
